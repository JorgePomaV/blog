Como almacenar rutas en cache?: se usa para no tener que recargas en cada solicitud y acelerar el sistema.

Route resourse: se crean rutas con una sola linea de codigo, se usan cuando solo se necesitan rutas preterminadas de curd laravel.
                tambien se pueden customisar.

Route con Invoque: se usa cuando solo un controlador tiene solo una ruta, simplifica lineas de codigo y buenas practicas.

Grupo de rutas: alternativa a Route resourse ya que simplifica cuando tenemos rutas que no son preterminadas de un CRUD laravel
                se puede simplificar si tienen el mismo prefijo y name.


    

Directivas Environments: Se usa para controlar qué se muestra o ejecuta según el entorno, evitando que en producción 
                        aparezcan cosas que solo sirven para desarrollar o depurar, y garantizando que la configuración 
                        se ajuste al entorno sin cambiar manualmente el código cada vez.
                        se configuta en .env



Forelse: recorre el array y verifica al mismo tiempo si hay datos.


contie y break en laravel: se puede poner condiciones en la misma linea

Variable loop: da informacion de un bucle de for, podes obtener informacion del primer o ultimo, etc..

Directiva @class: sirve para agregar estilos a ciertas clase que queramos con condicionales

Atributos adisionales para formularios: hay valdiaciones por ejemplo readonly es para que no pueda ingresar un dato
                                        el laravel hay atributos para poder controlar eso con validaciones que mandamos
                                        por backend.

Cmponentes de clase: se usa para reutilizar partes de codigo mas especificas y perzonalisables.
Include: se usa pora reutilizar vistas.

Componentes anonimos: Usa componentes anónimos cuando necesites reutilizar HTML con variables, pero no lógica compleja.
Si necesitas procesar datos antes de mostrarlos, ahí ya conviene un componente de clase.

Componentes como plantilla: es la forma de trabajo desde la version 7.(Mas usada hoy en dia, mas que nada por jeststream)
Herencia de plantilla: es la forma de trabajar antes de la version 8.

Directiva @stack: sirve para apilar componentes por ejemplo estilos, meta descripciones, script.(se puede usar en componentes de platilla y herencia de plantilla)



Revertir cambios: rollback/fresh/refresh

    El comando: php artisan migrate::rollback
    
    solo volvera a reestablecer los cambios del ultimo lote.

    1️⃣ php artisan migrate:fresh

    Qué hace:
    Borra TODAS las tablas de la base de datos.
    Ejecuta de nuevo TODAS las migraciones desde cero.

    2️⃣ php artisan migrate:refresh
    Qué hace:
    Ejecuta el método down() de todas las migraciones (esto revierte cada migración una por una).
    Luego ejecuta el método up() de todas las migraciones (las vuelve a correr).
